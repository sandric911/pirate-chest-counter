Счётчик сундуков Fortnite (мини-сезон Treasure Hunters, v43.x) по файлам повторов.

**Установка:** скачайте `PirateChestCounter.exe` и запустите (SmartScreen: «Подробнее» → «Выполнить в любом случае»),
или попросите Claude: «Установи счётчик сундуков из github.com/sandric911/pirate-chest-counter».
Проверка файла: `SHA256SUMS.txt`.

Уже установленная программа обновится сама.
