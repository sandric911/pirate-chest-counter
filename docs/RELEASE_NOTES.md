Счётчик сундуков Fortnite (мини-сезон Treasure Hunters, v43.x) по файлам повторов.

**Установка и обновление:** скачайте `PirateChestCounter.exe` и запустите (SmartScreen: «Подробнее» → «Выполнить в
любом случае»). Новая версия ставится поверх старой, статистика и копии реплеев сохраняются.
Проверка файла: `SHA256SUMS.txt`.
